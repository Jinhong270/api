# 贪吃蛇

经典贪吃蛇，开箱即玩。操控一条小蛇在地图上穿梭，吃掉食物、越变越长，同时别撞墙、别咬到自己。

界面按浏览器语言自动切换，没有语言选择页。简体中文、台湾、香港、澳门各自使用不同说法；英语、日语、德语、法语、西班牙语等主流语言也有独立语言包。浏览器语言不在支持列表里时，使用 English (United States)。

## 怎么玩

- 小蛇会自动向前移动，你只需要控制方向。
- 吃到食物得 **10 分**，身体会变长一格。
- 撞到边界或撞到自己的身体，游戏结束。
- 目标很简单：在你选的速度下，尽量拿更高分。

## 操作方式

### 电脑端

| 操作 | 按键 / 方式 |
|------|-------------|
| 移动 | 方向键，或 **W A S D** |
| 开始 / 暂停 / 继续 | **空格键**或 **Enter**，或点击游戏画面 |
| 暂停 | **Esc** |
| 全屏 | **F**，或标题栏全屏按钮（浏览器支持时） |
| 重新开始 | 点击「重新开始」按钮 |

### 手机 / 触屏

| 操作 | 方式 |
|------|------|
| 移动 | 在画面上**滑动**，或使用**虚拟方向键** |
| 开始 / 暂停 / 继续 | **轻点**游戏画面，或点方向键**中间的圆钮** |
| 显示 / 隐藏方向键 | 点击「显示方向键 / 隐藏方向键」 |

开局前直接滑动，会开始游戏并立刻朝那个方向走。速度、背景色和方向键开关会记在本机。切到别的应用时会自动暂停。浏览器允许时，对局中屏幕会保持常亮。

> 提示：不能直接掉头（例如正在向右时不能立刻向左），避免一不小心咬到自己。连续点两个方向会先记下来，快速拐弯更跟手。

## 屏幕适配

页面锁在当前可见区域里，棋盘保持正方形，并尽量占满剩下的空间：

- **手机竖屏**：棋盘在上，方向键贴在棋盘下方，速度和颜色收在底部。屏幕较矮时，设置可以滚动，不会把棋盘挤没。
- **手机横屏**：设置在右侧。方向键一般在棋盘左侧，两只手都能碰到。
- **平板竖屏**：设置并成两列，把高度留给棋盘。
- **平板横屏和电脑**：棋盘放大居中，设置固定在右侧。
- **超宽屏和大显示器**：整页居中，棋盘继续放大，直到大约 1600 像素。

窗口比例很怪时（分屏、折叠屏、拉得很窄的浏览器），方向键会自动改到棋盘下方或左侧，哪边能让正方形更大就放哪边。

## 速度模式

开局前（或暂停 / 结束后）可以切换四种速度，**进行中无法切换**：

| 模式 | 手感 |
|------|------|
| 慢速 | 节奏宽松，适合熟悉操作 |
| 正常 | 默认速度，平衡手感 |
| 快速 | 反应要跟上 |
| 极速 | 极限挑战 |

每种速度会**单独记录最高分**。刷新页面后最高分仍会保留在本机。

## 小功能

- **暂停**：随时喘口气，再继续冲高分。
- **背景色**：设置里可选多种深色主题（经典黑、深邃蓝、暗夜绿等），换个氛围再战。
- **新纪录**：打破当前速度下的最高分时，结算界面会显示「新纪录」。

## 开始一局

1. （可选）选好速度和背景色  
2. 点击「开始游戏」，或按空格 / 点画面  
3. 控制方向吃食物，活得越久、分越高  
4. 结束了？再来一局，冲更高纪录  

祝你玩得开心，蛇越长越好 🐍
